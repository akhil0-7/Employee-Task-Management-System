# Employee Task Management System

A React-based Employee Task Management System for creating, managing, searching, filtering, updating, and deleting employee tasks.

## 🚀 Features

- Create new employee tasks
- View all tasks
- Edit and update existing tasks
- Delete tasks
- Search tasks by title
- Filter tasks by:
  - Employee
  - Priority
  - Status
- Combine multiple filters
- Task status management
- Client-side form validation
- Dynamic task summary
- Empty-state messages
- Responsive user interface
- Reusable React components

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite

## 📋 Task Information

Each task contains:

- Task Title
- Employee
- Priority
- Due Date
- Status

- Completed
